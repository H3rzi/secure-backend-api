# secure-backend-api
## Overview
A secure backend API built with FastAPI to explore how real-world services handle authentication, data persistence, and access control.

## Why I built this
I wanted hands-on experience designing and implementing a backend system similar to those used in production software.

## Tech Stack
- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Docker (planned)

## Planned Features
- User registration and login
- JWT-based authentication
- Protected API endpoints
- CRUD operations
- Basic tests

## Stretch Goals
- Rate limiting
- Role-based access control
- CI with GitHub Actions
- Deployment
